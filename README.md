# Anatomy Explorer

Anatomy Explorer is a lightweight web-based educational application for interactive human organ visualization. It provides a focused experience for exploring organ structure, reading concise anatomical information, and switching between 2D and 3D perspectives.

## Features

- Interactive organ exploration interface
- 3D rendering with camera controls and zoom
- 2D and 3D view modes
- Organ-specific educational descriptions and quiz content
- Bilingual interface support (English and Amharic)

## Project Structure

- `index.html` — landing page for organ selection
- `explorer.html` — visualization and anatomy details interface
- `renderer.js` — rendering, interactions, and organ logic
- `models/` — 3D organ assets (`.glb`)

## Getting Started

1. Clone the repository.
2. Open `index.html` in a modern browser.
3. Select an organ to start exploring.
